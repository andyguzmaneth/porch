porch

Paid Onchain Reads. Correct & Hidden.

experimental · toy demo

The idea

Most wallets read the chain through one centralized RPC that sees every address you look up. Porch turns the thousands of nodes people already run at home into a marketplace for private, paid reads: a node opens a small confined RPC port, self-registers, and a wallet reads the chain through a rotating set of homes — unlinkably.

your node's RPC ──► porch-node ──► registry ◄── this page (allowlisted) (directory) picks a node, reads

Try it locally

Node 18+. No install, no dependencies. Three terminals:

# 1) the directory
node demo/registry/registry.mjs

# 2) a "home node" — wrap any Ethereum RPC (yours, or a public one)
node demo/porch-node/porch-node.mjs \
  --rpc https://ethereum-rpc.publicnode.com --name alice-porch --port 8646

# 3) this page
cd demo/website && python3 -m http.server 8080   # open http://localhost:8080

Start another node on --port 8647 --name bob-porch to see two homes appear.
